## 设计

石料使用灰褐断面；凝胶使用青绿稠块；尖牙使用磨旧象牙。三者以块状、团状、弯曲长尖状区分，颜色取自已定稿材质。实际木头参考为 Tiny Swords Icon_02，不是旧 Sprites_wood。

塔采用同一套八角石塔语言：一级保留石基、拱门、垛口和齿徽；二级加入扶壁、箭窗和双齿饰；三级加入侧护塔、四齿冠和菱形碑饰。石材、旧金束带与象牙来自正式齿骨遗迹背景，青灰侵蚀只作为少量细节。三级沿用共同视角和左上光源。

三张地图分别读取自原项目的 Sprites_map_1 / 2 / 3，不使用工作树旧地图或 output/MapArt 草稿。references 内为只读来源的副本，便于对照，均未被修改。

## 检查结果与局限

六张文件均为 1254 × 1254、32 位 RGBA PNG，确认含真正的 Alpha=0 像素；不是把棋盘格当透明。全透明区域比例：

| 素材 | 全透明占比 | 主体包围盒（Alpha ≥128） |
|---|---:|---|
| stone | 72.47% | [228, 237, 1035, 1048] |
| gel | 83.68% | [293, 358, 1013, 911] |
| fang | 81.96% | [202, 183, 1111, 1050] |
| tower1 | 73.29% | [330, 256, 948, 1068] |
| tower2 | 64.34% | [281, 135, 986, 1131] |
| tower3 | 58.17% | [217, 47, 1037, 1140] |

包围盒为 [左,上,右,下)，右下不含。主体均未触到画布边缘。原始图像视觉检查未见棋盘底、文字、水印或主体明显缺件，结构和配色符合本轮方向。但仍存在以下限制：

- 有低透明度散点与半透明边缘，塔的画布边缘分别出现 14 / 9 / 7 个非零 Alpha 像素。这些不是主体被截断。大部分主体 Alpha 接近 255（集中在 253），并非全部完全不透明。没有用脚本强行阈值抠图，也没有宣称生产级边缘已完成。
- 塔的原始底边为 1068 / 1131 / 1140，一级与二级相差 63 像素。预览按可见包围盒作显示裁切并对齐，原 PNG 未改写。后续选定造型后仍需统一画布落点。
- 这批是生成式像素风候选，尚未整理为严格固定像素网格。
- 对照页已提供 32 / 48 像素显示、正式地图叠放及深浅底色检查。内置浏览器阻止访问本地 file URL，因此页面尚未完成浏览器视觉实测，也不把小尺寸可读性称为已验证。预览不是 Unity 截图，不代表最终比例或游戏效果。
- 背景、角色和现有木头只作对照，未替换正式引用。
