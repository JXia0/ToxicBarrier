# ToxicBarrier portfolio

Use `ToxicBarrier_Portfolio_6_Slides_EN_v6.pptx` for the current six-slide English version. Slide 1 includes a short backstory with the full narrative in its speaker notes and in `Backstory.md`. Slide 5 includes all four resources: wood, stone, gel and teeth.

The cover follows the supplied Candle Castle composition: a full scene, large title logo, short concept, vertical tool icons and one repository link. Content removed from the previous cover has been redistributed across the other five slides.

1. Cover and one-sentence concept
2. How to play, core mechanics, controls and victory condition
3. Level design and progression through three regions
4. Actual C# source excerpt and the gameplay effect of cover
5. Solo development responsibilities, development period, production process and sprite integration
6. Game gallery, video area, empty player-playtest area and pending The Rookies link

The deck contains five distinct game screenshots. The title illustration is promotional artwork. The development start date comes from the initial repository commit, 27 December 2025. Text, code and layout elements remain editable; game art and screenshots are embedded images. Source details are in slide notes.

## Logo asset

`ToxicBarrier_Logo.png` is the separate 1536×1024 PNG used in the deck. It contains alpha transparency and has fully transparent corners. The built-in image generation tool produced it for this portfolio; it has not replaced any Unity asset.

Prompt:

> Use case: logo-brand. Create a polished game title logo for the indie dark fantasy pixel-art survival tower-defense game. Exact title in two stacked lines: "TOXIC" on the first line and "BARRIER" on the second line. Only these words. Broad readable custom medieval slab serif letterforms, mature editorial restraint rather than a busy esports badge. Weathered ivory and antique gold faces, discreet charcoal bevel and very thin desaturated teal edge accents; matte stone and aged metal, not shiny plastic. The game features a black cloaked defender protecting a friendly stone tower in tooth-themed medieval ruins with bronze tiles, teal poison and burgundy foliage. Include one small stylized ivory fang integrated below the wordmark and a restrained crenellated silhouette in the upper letter shapes, not a separate illustration. Strong simple silhouette readable at 350 pixels wide. Logo only, centered and closely framed with generous transparent margin, landscape canvas approximately 3:2. Genuine transparent alpha background outside lettering and ornament. No square background, no checkerboard drawn into the image, no screenshot, no extra slogan, no watermark. High-quality original 2D game title typography.
