# 中文字体

Noto Sans CJK SC Regular，来自 Noto 官方仓库：
https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

字体随项目携带，不依赖玩家电脑安装中文字体。许可证见同目录 OFL.txt（官方 Sans/LICENSE 原文）。
TMP 字库位于 Assets/Resources/Presentation/Chinese.asset，由 ReleasePolishTool 生成；采用动态字库并保留源字体，支持后续新增中文文案。
